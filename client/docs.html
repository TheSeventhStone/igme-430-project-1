/getTypes

Gets all Pokemon of a specified type.

Query parameters:

  • type (required) - an offical Pokemon type to filter by.
  • secType (optional) - an offical Pokemon type to further filter by.

Returns

A JSON array of Pokemon. Format: [obj]

Examples

/getTypes?type=fire&secType=flying >>> [{pkm1 (Charizard)},{pkmn2 (Moltres)}]

/getTypes?type=grass >>> [{pkm1},{pkmn2},...{pkmn13}]

/catchEm

Gets Pokemon meeting parameters

Query parameters:

  • type (required) - an offical Pokemon type to filter by.
  • secType (optional) - an offical Pokemon type to further filter by.
  • name (optional) - a name fragment to filter by.

Returns

A JSON array of Pokemon. Format: [obj]

Examples

/catchEm?name=saur >>> [{pkm1 (Bulbasaur)},{pkmn2 (Ivysaur)},{pkmn3 (Venusaur)}]

/getTypes?type=flying&name=char>>> [{pkm1 (Charizard)}]

/dexNav

Gets Pokemon by name

Query parameters:

  • name (required) - a name fragment to filter by.

Returns

A JSON array of Pokemon. Format: [obj]

Examples

/dexNav?name=saur >>> [{pkm1 (Bulbasaur)},{pkmn2 (Ivysaur)},{pkmn3 (Venusaur)}]

/getTypes?name=Agumon >>> Message: No such Pokemon in the Pokedex

/catchEmAll

Gets all available Pokemon

Query parameters:

No supported parameters

Returns

A JSON array of Pokemon. Format: [obj]

Examples

/catchEmAll >>> [{pkm1},{pkmn2},...{pkmn151}]

/scanIn

Adds a new Pokemon to the Pokedex API

Accepted Formats

application/json

Body parameters:

  • num (required) - number
  • name (required) - string
  • img (optional, publicly hosted image URL of pokemon) - string
  • type (required,max 2) - string[]
  • height (optional, in meters) - number
  • weight (optional, in kilograms) - number
  • weak (optional, comma-separated values) - string
  • evo (optional, next evolution(s) of pokemon) - Object[{name,num}]

Returns

Nothing returned
